# Hydronium LUAX

`moonstone/hydronium-luax` is the `.luax` compiler, formatter, LuaLS plugin, and editor
integration package.

```sh
moon add moonstone/hydronium-luax
```

It installs the `hydronium_luax` Lua namespace. Its Neovim plugin is shipped
under `nvim/` and exposes `require("luax").setup()`.
